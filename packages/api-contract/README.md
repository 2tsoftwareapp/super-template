# @repo/api-contract

**Generated** OpenAPI contract types — the source of truth shared by web, admin, and (via Dart codegen) mobile.

- `src/generated/` — regenerated by `pnpm generate`; never hand-edit.
- `src/sort/multi-sort.ts` — re-export of `@repo/api-sort` so frontends get sorting types from the contract package without depending on backend packages. Frontend imports sorting from **here**; backend imports it from `@repo/api-runtime`.

After changing any NestJS controller/DTO/decorator: `pnpm generate` and commit the regenerated output (CI runs `generate:check` against drift).
