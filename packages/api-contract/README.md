# @repo/api-contract

**Generated** OpenAPI contract types — the source of truth shared by web, admin,
and (via Dart codegen) mobile.

- `src/generated/` — regenerated by `pnpm generate`; never hand-edit.
- `bffPath` helper — shared BFF path utilities.

Sorting helpers live in `@repo/api-sort` (import that package directly).

After changing any NestJS controller/DTO/decorator: `pnpm generate` and commit
the regenerated output (CI runs `generate:check` against drift).
