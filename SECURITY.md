# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report them privately through GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) (the **Security** tab → **Report a vulnerability**), or contact the maintainers directly.

When reporting, include:

- A description of the vulnerability and its impact
- Steps to reproduce or a proof of concept
- Affected versions or components, if known

We aim to acknowledge reports within a few business days and will keep you informed as we work on a fix.

## Supported versions

This is a project template. Security fixes are applied to the `main` branch. Forks and projects derived from this template are responsible for their own security posture.
